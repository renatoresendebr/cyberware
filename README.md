# Cyberware Tecnologias LTDA

Política pública única de privacidade para todos os aplicativos da Cyberware Tecnologias LTDA. Cada seção se aplica conforme os recursos e serviços utilizados por cada app. Exemplos específicos do Imagens com Frases aparecem identificados no texto.

- [Política de Privacidade — Português](https://renatoresendebr.github.io/cyberware/privacy-policy.html?lang=pt)
- [Privacy Policy — English](https://renatoresendebr.github.io/cyberware/privacy-policy.html?lang=en)
- [Política de Privacidad — Español](https://renatoresendebr.github.io/cyberware/privacy-policy.html?lang=es)

URL única para cadastro na Play Console: **https://renatoresendebr.github.io/cyberware/privacy-policy.html**.

A página escolhe o idioma pelo parâmetro `?lang=pt`, `?lang=en` ou `?lang=es`, pelo fragmento de idioma ou pelo navegador. O seletor permite alterar o idioma a qualquer momento. Sem JavaScript, os três textos permanecem disponíveis.

## Atualização

Os textos estão em `content/pt.txt`, `content/en.txt` e `content/es.txt`. Ao alterar a política, atualizar os três idiomas e a data e regenerar a página com:

```sh
python scripts/build_policy.py
```

O gerador usa apenas a biblioteca padrão do Python. Conferir `privacy-policy.html` e publicar a alteração em `main`. GitHub Pages usa a raiz dessa branch. A página não depende de recursos externos, não usa cookies, armazenamento local ou ferramentas de medição próprias. A hospedagem continua sujeita às práticas do GitHub.
